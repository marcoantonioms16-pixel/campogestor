# CampoGestor — Visual Premium v2

Esta versão faz uma renovação visual ampla sem alterar as regras de negócio.

## O que mudou
- novo sistema de cores e tipografia;
- fundo fotográfico da fazenda em toda a experiência;
- shell central com efeito translúcido;
- cabeçalhos renovados;
- cards, listas, formulários, botões e chips com padrão único;
- navegação inferior refinada;
- menu lateral refinado;
- splash renovado;
- responsividade para celular e desktop.

## Regra de manutenção
A aparência principal deve ser alterada em `css/app.css`. A estrutura visual compartilhada do cabeçalho e shell fica em `js/app.js`. A lógica específica de cada tela continua em `js/telas/`.
