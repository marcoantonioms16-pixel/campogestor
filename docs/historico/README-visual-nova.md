# CampoGestor — Visual Nova

Esta versão altera **somente a camada visual** do projeto original enviado.

## O que foi feito
- novo design system premium;
- fundo agrícola visível usando `assets/splash-fazenda.jpg`;
- cards, botões, campos, listas, chips e badges redesenhados;
- menu hamburger/balões existente recebeu novo acabamento;
- navegação inferior escondida, conforme solicitado anteriormente;
- responsividade para celular e desktop.

## O que NÃO foi alterado
- `js/app.js`;
- arquivos de dados/configuração;
- arquivos das telas;
- lógica de filtros, cadastros, salvamento e sincronização.

O objetivo é permitir testar uma nova aparência sem reintroduzir regressões de lógica.
